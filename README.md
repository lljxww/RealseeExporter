# RealseeExporter

从本人有权访问的爱空间分享链接备份房屋水电 VR 全景，并生成可离线浏览页面，供后续检修、
改造和墙面施工时查阅隐蔽工程位置。

## 项目背景与用途

房屋装修完成后，水管、电线等隐蔽工程会被墙面和地面覆盖。装修平台提供的线上 VR 记录
通常依赖第三方服务持续运营；如果服务调整或停止，原有资料可能无法继续访问。此类资料对
后续水电检修、局部改造、墙面打孔和安装设备具有长期参考价值。

RealseeExporter 因个人住房资料备份需求而开发，是一个供本地使用的 .NET 10 工具。它接收
用户本人有权访问的 `https://realsee.ikongjian.com/vr/PK...` 公开分享链接，读取全景项目数据，
下载每个拍摄点的 6 张 Cube Map，并生成包含离线 Three.js 查看器的 ZIP 文件。

本项目适用于经授权的个人备份、内部归档和离线展示，不用于破解、绕过登录或访问控制，
也不提供批量采集、账号认证或非公开资源访问能力。

## 本地使用

### 环境要求

- .NET 10 SDK
- 可访问目标公开分享链接及相关静态资源的网络环境

### 启动服务

```bash
dotnet run
```

打开控制台显示的本地地址（例如 `http://localhost:5000`），粘贴公开分享链接，
然后点击“下载并打包”。下载过程需要联网；生成的 ZIP 可在本地保存和解压。

建议仅在本机环回地址上运行，不要直接将本项目作为公网下载服务部署。

### 浏览导出项目

浏览器通常会阻止直接打开的网页读取本地全景图片，因此请先完整解压 ZIP，不要在压缩包内
打开，也不建议直接双击 `index.html`。推荐使用 Visual Studio Code 的 Live Server：打开解压后的
项目文件夹，右键单击 `index.html`，选择 **Open with Live Server**。如果没有这个选项，可先在
Visual Studio Code 的“扩展”中搜索并安装 **Live Server**。

如果电脑已经安装 Python，也可以打开解压后的项目文件夹，在文件夹地址栏输入 `cmd` 并回车，
然后在出现的窗口中运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

再访问 `http://127.0.0.1:8000/`，使用完毕后关闭命令窗口。每个导出的 ZIP 中也包含一份面向
普通用户的 `README.txt` 操作说明。

## 技术边界

- 当前只接受 `realsee.ikongjian.com` 分享链接。
- 资源下载只允许 `ikongjian.com` / `aliyuncs.com` 子域，以降低 SSRF 风险。
- 当前采用内存打包，适合个人或内部、小规模使用。若用于受控的多人服务，应改为临时文件或
  流式打包，并增加身份认证、并发限制、大小限制、速率限制、审计和缓存。
